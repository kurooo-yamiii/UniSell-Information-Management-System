# 👔 Vestia – Uniform & Slacks POS System

**Vestia** is a Point-of-Sale (POS) web application designed to streamline the selling and management of **school uniforms and slacks**.  
It provides efficient inventory tracking, transaction management, and sales monitoring for uniform retail stores.

---

## 🚀 Features

- 🧾 Manage sales transactions for uniforms and slacks  
- 👕 Product and inventory management  
- 👩‍💼 User authentication and access control  
- 💰 Real-time sales reports  
- 🧠 Built with **ASP.NET Framework (C#)** and **SQL Server**

---

## 🏗️ Tech Stack

| Category | Technology |
|-----------|-------------|
| **Frontend** | HTML, CSS, JavaScript |
| **Backend** | ASP.NET Framework (C#) |
| **Database** | SQL Server |
| **UI Hosting** | `wwwroot` Static Files |
